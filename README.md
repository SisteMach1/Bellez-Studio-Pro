# BELLEZA STUDIO PRO - APK Manicuras Peluqueras Estilistas

APP 100% offline, PWA instalable como APK

## INSTALAR EN GITHUB:

1. Crear repo nuevo: belleza-pro
2. Subir estos 3 archivos: index.html, manifest.json, service-worker.js
3. Settings > Pages > main > Save
4. Tu app: https://tuusuario.github.io/belleza-pro/
5. Clave acceso: 2025 (cambiala en Configuracion)

## FUNCIONES:

- Catalogo con fotos/videos y precios editable
- Galeria trabajos con selfie al momento (camara)
- Clientes ilimitados: nombre, abono, debe, turno, trabajo, transferencia/efectivo
- Dashboard con deudas y turnos
- Exportar CSV, backup JSON
- Fuente hermosa Playfair + Plus Jakarta Sans
- Funciona online y offline como APK

## INSTALAR COMO APK EN CELU:

Chrome > Menu > Instalar app > queda icono rosa B
